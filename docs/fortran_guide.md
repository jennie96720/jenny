# 用 Fortran 重写 quark + diquark Faddeev 框架：学习指南

目标：自己从零实现 arXiv:2611.19819（核子引力形状因子）所用的 quark+diquark 框架，并能和
本仓库的 Python 参考实现（`qdq/`）逐步、逐位核对。

- 参考数值：`docs/reference_values.md`（由 `scripts/make_reference_values.py` 生成）
- **完整的 Fortran 程序**：`fortran/`（按介子 DSE/BSE 程序的结构组织，见 `fortran/README.md`），
  所有阶段都已和 Python 逐位核对。建议你自己重写其中的 Faddeev 核（第 3–4 步），其余部分读懂、改着用。

---

## 0. 总体做法

1. **每一步都要能和参考值比对**（`fortran` 的 `check` 模式就是这样做的）。先比对，再往下走。
   这比写完整个程序再调试快得多。
2. **用和 Python 完全相同的积分网格**（`fortran/sources/_libraries/quadrules.f90` 已实现同样的规则），这样网格相关的数
   （比如某个网格上的本征值 λ(M)）可以逐位比对，而不只是比到"物理精度"。
3. **Python 是你的"标准答案生成器"**：任何中间量都可以用几行 Python 打印出来，比如：
   ```bash
   cd /path/to/jenny
   python3 -c "
   import numpy as np; from qdq.quark import S
   print(S(np.array([0.1, 0.2, 0.3, 0.4j])))      # 某个复动量处的 4x4 传播子
   "
   ```
4. 先读文献（建议顺序）：
   - Alkofer 等 nucl-th/0412046 第 2 节：Faddeev 方程的完整写法（−4 因子、动量分配、四块核）
   - arXiv:2611.19819 附录 A、B：所有输入、基矢、色味系数
   - Cloët 等 0812.0416 附录 C、D：电磁流各图、Chebyshev 展开
   - Cheng 等 2507.13484 第 3 节：改进后的电磁流（未截腿顶点、seagull）
   - 2611.19819 第 3 节：引力子顶点

## 1. Fortran 工程建议

- **类型**：所有动量、矩阵都用 `complex(dp)`，因为核子总动量 P = (0,0,0,iM) 是复的。点积**不取共轭**
  （`dot4` 已给出），这是欧氏空间的解析延拓，不是 Hermitian 内积。
- **复数常量**：`cmplx(a, b, kind=dp)` 一定要写 `kind=dp`，否则会被截成单精度，这是 Fortran 最常见的坑。
- **数组布局**：Fortran 是列优先。把 Dirac 指标放在最前面，如 `psi(4,4,N)`、`chi(4,4,4,N)`，内层循环
  更快，也方便直接调用 `zgemm`。
- **模块划分**：见 `fortran/README.md`（`_libraries` + `zero_quark / zero_diquark / zero_faddeev /
  zero_normalization / zero_probe / zero_current1 / zero_current2`，每个阶段 elems / utils / solve）。
- **线性代数**：本征值问题用 LAPACK `zgeev`（非厄米复矩阵）；大矩阵乘法用 `zgemm`。
- **并行**：最外层的外点循环（Faddeev 核的外动量、双圈积分的外圈 k）用 OpenMP `!$omp parallel do`，
  每个线程有自己的累加器，最后再归约。
- **调试**：`make FFLAGS="$(DEBUG)"` 打开越界检查和浮点异常陷阱。

## 2. 分步路线（每步：做什么 / 依据 / 检验 / 坑）

### 第 1 步：γ 矩阵、夸克传播子、求积
- 文件：`fortran/sources/_libraries/{constant,dirac,quadrules,special}.f90`、`fortran/sources/zero_quark/`
- 检验：`check` 模式与 `docs/reference_values.md` 第 1 节逐位一致，M^E = 0.3275076942。
- 要点：σ_V、σ_S 是整函数，复 p² 直接算即可；F(x) 在 x→0 用级数。

### 第 2 步：diquark 振幅与归一化 → g₀₊、g₁₊
- 依据：2611.19819 Eqs. (A5)–(A12)；Alkofer Eq. (15)（Dirac 结构用 **C iγ₅** 和 **iγ_μ C**）。
- 做法：Π(Q;K) = Tr ∫ Γ̄(q;−K) S(q+Q/2) Γ(q;K) Sᵀ(−q+Q/2)，K = (0,0,0,im)。
  对 K_μ 收缩后：2K² = dΠ(αK)/dα|_{α=1}（轴矢量再对横向投影 T_αβ 收缩，左边乘 3）。
  α 的导数用中心差分即可。积分只依赖 |q| 和 q₄，所以只需二维积分（|q|, z）。
- 检验：g₀₊² = 56.8688，g₁₊² = −42.4008（颜色迹取 2，味道矩阵归一到 1）。
- **坑**：
  1. 在我们的 γ 表示下 **g₁₊² < 0**，必须保留 g₁₊ = +i|g₁₊|，并在 Faddeev 核里用 g_X g_Y（不能取模）。
     否则会得到一对纯虚的伪本征值。
  2. 论文给出的 14.94 和 12.98 是我们 |g| 的 2 倍，这只是记账约定不同。和 Faddeev 核的 −4 前因子一起用时，
     应该取 **论文值 / 2**（即 7.47 和 6.49i），或者直接用你自己算出的 g。

### 第 3 步：Faddeev 核
- 依据：Alkofer Eqs. (8)–(13)；味道系数来自 2611.19819 附录 B 的图 4 公式（去掉探针）。
- 核：ψ_X(k) = −4 Σ_Y c_XY g_X g_Y ∫ Γ^Y(k_q − ℓ_qq/2) Sᵀ(ℓ_qq − k_q) Γ̄^X(ℓ_q − k_qq/2) S(ℓ_q) Δ^Y(ℓ_qq) ψ_Y(ℓ)，
  其中 ℓ_q = ℓ + P/3，ℓ_qq = −ℓ + 2P/3（k 同理）。**注意 Dirac 顺序**：入射 diquark 的 Γ^Y 在最左边。
- 味道系数 c_XY = Σ φᵀ (s^m)ᵀ t^n (t^m)ᵀ s^n φ：先自己手算，再和参考值比：c_ss = ½，c_sa = c_as = −√3/2，c_aa = −½。
- 振幅基矢：2611.19819 Eq. (A15)，S¹、S² 以及 γ₅A¹…⁶_ν，右乘 Λ₊ = (1+γ₄)/2。
- 投影：用对偶基（Gram 矩阵求逆），见 `qdq/faddeev.py` 的 `_duals`。
- 积分变量：|ℓ|、z = ℓ₄/|ℓ|（Chebyshev 第二类）、y = k 和 ℓ 三维部分夹角的余弦（Gauss–Legendre），
  剩下的方位角给出 2π。外点放在 (0, 0, |k|√(1−z²), |k|z)。

### 第 4 步：本征值与核子质量
- 用 Nyström 离散，把核写成矩阵，再用 `zgeev` 求实部最大的本征值 λ(M)，用割线法解 λ(M) = 1。
- 检验（逐位，网格 (n_r,n_z,n_y) = (8,4,4)，scale 0.6，g = (7.47, 6.49i)）：
  λ(1.18) = **1.0154017190**；只留标量 diquark 时 λ(1.18) = 0.3464548163。
- 物理检验：M_N = 1.1787 GeV（论文 1.18）；只留标量 diquark 时 1.459 GeV（Alkofer 1.46）。

### 第 5 步：Chebyshev 振幅
- f_c(ℓ², z) = Σ_n f_{c,n}(|ℓ|) U_n(z)，外点只需要取 N_cheb 个 Chebyshev 节点。
- 检验：N_cheb = n_z 时与 Nyström 的本征值完全一致；M_N 随 N_cheb 收敛：1.111、1.185、1.178、1.1788（N_cheb = 1, 2, 3, 4）。
- 写一个函数，在任意 ℓ 和 boost 后的 P 处给出 8 个标量函数（径向用样条，z 可以是复数），后面所有流都要用它。

### 第 6 步：单圈电磁流（图 1–3）和归一化
- 依据：Cheng 2507.13484 第 3 节（顶点公式）；Breit 系 P_{f,i} = (0,0,0,iE) ± Q/2。
- 共轭振幅：Ψ̄(p;−P) = C† Ψ(−p;−P)ᵀ C。
- **形状因子提取**：在每个积分点上先做洛伦兹标量的迹投影，再积分；这样方位角积分可以直接给 2π。
- **归一化不需要双圈图**：完整重子数 = −(∂λ/∂P_μ)·Ψ̄G₀Ψ，dλ/dM 用 λ(M±h) 的差分即可。
- 检验：
  1. 每个顶点在随机复动量处满足 WGTI，误差约 1e-14；
  2. Q = 0 时，用重子数电荷算出的图 1+2 等于有限差分算出的 −Ψ̄(∂G₀/∂P)Ψ，至少 7 位一致；占重子数的 80.26%；
  3. 归一化后，图 1–3 给出 F₁ᵖ(0) = 0.817，F₁ⁿ(0) = −0.014。
- **坑**：0⁺↔1⁺ 跃迁顶点的相位和两个方向的相对符号依赖 γ 表示。照搬论文的 χ¹⁰ = −χ⁰¹，两项会严格抵消。
  在我们的约定下应该取 χ¹⁰ = +χ⁰¹，κ 带相位 −i。这是用 diquark 内部的夸克三角圈图推出来的，见
  `qdq/current.py` 的 `transition_kappas`。

### 第 7 步：双圈图（图 4–6）
- 做法：对**你自己的** Faddeev 核做规范化（gauging），在核里的每条线上插入光子：
  交换夸克 Sᵀ(q) → [iχ(q′,q)]ᵀ；Γ 和 Γ̄ 的动量依赖给出 seagull。出射腿用 Oettel 的 X；
  **入射腿的 X̄ 要多一个负号**。
- 检验：
  1. 不加光子时 Ψ̄G₀KG₀Ψ = Ψ̄G₀Ψ（本征值为 1），这一项检验积分本身和左右取向；
  2. 用重子数电荷时，图 4 等于 −Ψ̄G₀(∂K/∂P)G₀Ψ，seagull 为 0；
  3. F₁ᵖ(0) = 1，F₁ⁿ(0) = 0，u 数 = 2，d 数 = 1。
- **性能**：先对外点 k 和内点 ℓ 各自预先算好与对方无关的部分，再把对 (μ′, ρ, Dirac) 的求和写成一次
  `zgemm`。这样外点每个只需几毫秒（见 `qdq/exchange.py`）。

### 第 8 步：引力形状因子
- 顶点：电磁顶点 × ℓ_ν − δ_μν × (两端传播子的平均)，夸克顶点再加上标量介子极点项（2611.19819 Eqs. 14–19）。
- **diquark 的味道因子取两个夸克的平均**，即电磁那种求和的一半；否则 diquark 的动量会被重复计算。
- seagull：电磁结构分别乘以腿的动量（出射腿用 k_q、q′，入射腿用 ℓ_q、q），再加 δ_μν/2·Γ。
- 投影：用 2611.19819 Eq. (5)–(6) 的 s₁…s₅。**Q = 0 时 γ⊥ 要取沿 Q̂ 方向的极限**。整体相位由 A(0) = +1 确定。
- 检验：A(0) = 1；令 r_sc = r_av = 0 时，所有 Q² 上 Σc̄ = 0；对照数据见 README。
- **坑**：J、D 的提取公式里有 1/τ，小 Q² 处会放大网格误差，需要细的双圈网格（例如 x = 0.02 时 D 从
  粗网格的 −2.62 变成细网格的 −2.47）。

## 3. 仍然开放的问题（可以作为你的研究练习）

1. **J(0) ≈ 0.479 而不是 ½**；S(0)、μ_p、μ_n 也偏低 3–5%。数值原因都已排除，问题出在自旋翻转耦合上。
   用你的 Fortran 程序独立实现一遍，本身就是最好的交叉检验：如果你得到 0.5，就说明 Python 版本有错。
2. **diquark 形状因子 F_J 应该怎样乘**才能保持能动张量守恒（c̄ = 0），同时让 A 对应物理半径？
3. 演化到 2 GeV（all-orders 方案），给出夸克和胶子的分解（2611.19819 表 3）。
